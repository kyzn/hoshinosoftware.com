Mapcoder

Mapcoder は、Apple マップの場所をカーナビで目的地に設定できる数字のマップコードに変換します。場所を共有して、iPhone に表示されたコードをカーナビに入力するだけです。コードは端末上で計算され、調べた場所は履歴に残ります。

お問い合わせの前に

不具合がある場合は、まず以下をご確認ください。

  • 共有シートに Mapcoder が表示されない場合 上段のアイコンと、その下のリストにある「マップコードを取得」の両方をご確認ください。リストに見つからない場合は、共有シートの一番下までスクロールし、「アクションを編集」から「マップコードを取得」を追加してください。以後は常に表示されます。
  • 他の地図アプリから共有しても Mapcoder が出てこない場合 他の地図アプリは座標を含まない短縮リンクを共有するため、Mapcoder はそれらの共有シートには表示されません。Apple マップからご利用ください。
  • 「現在地」ボタンが使えない場合 iPhoneの設定 → プライバシーとセキュリティ → 位置情報サービス → Mapcoder で「このAppの使用中のみ許可」を選んでください。
  • 「現在地」ボタンのコードが大まかな場合 iPhoneの設定 → プライバシーとセキュリティ → 位置情報サービス → Mapcoder で「正確な位置情報」をオンにしてください。オフの場合、現在いるブロックまたはゾーンまでしか特定できません。地図をタップして絞り込むこともできます。
  • マップタブの地図が表示されない場合 背景地図はインターネットから読み込むため、通信が必要です。マップコードの取得には通信は不要です。
  • カーナビがコードを受け付けない、または別の場所に案内される場合 場所、アプリが表示したコード、カーナビの機種を添えてご連絡ください。

よくある質問

  • マップコードとは何ですか？
    日本国内の地点を表す数字の並びです。多くのカーナビで目的地として入力でき、住所や電話番号を入れるより早く、どちらもない場所でも使えます。

  • インターネット接続は必要ですか？
    いいえ。マップコードは通信を一切行わずに iPhone 上で計算されます。インターネットから読み込むのはマップタブの背景地図だけです。

  • デンソーの公式アプリですか？
    いいえ。Mapcoder はデンソーとは関係がなく、デンソーによる承認やライセンスを受けたものではありません。運転の前に必ずカーナビの画面で場所をご確認ください。

  • 履歴はどこに保存されますか？
    iPhone 内にのみ保存され、外部に送信されることはありません。履歴タブで消去すれば削除され、アプリを削除すればすべて消えます。

  • 開発者は私が調べた場所を見られますか？
    いいえ。アカウントも開発者のサーバーも解析ツールもありません。調べた場所が端末の外に出ることはありません。

使い方

マップコードを調べる

Apple マップで場所を開き、共有ボタンから Mapcoder を選びます。上段のアイコン、または下のリストにある「マップコードを取得」のどちらでも使えます。座標は共有データそのものに含まれて渡されるため、通信なしですぐにコードが表示されます。カーナビに目的地として入力し、出発前にカーナビの画面で場所をご確認ください。

現在地のマップコード

「現在地」ボタンを押すと、今いる場所をマップコードに変換します。駐車した場所を控えたり、待ち合わせ場所を伝えたりするときに便利です。アプリの使用中に位置情報を使う許可が必要です。位置情報は iPhone 上で使われ、外部に送信されることはありません。

履歴

調べた場所はすべて履歴タブに残るので、Apple マップに戻らなくてもコードをもう一度確認できます。共有シートから調べた場所も記録されます。履歴タブで消去すれば削除されます。

マップ

マップタブでは、日本全国の地図にマップコードのゾーンを重ねて表示し、拡大して見られます。背景地図は国土地理院の地理院タイルで、表示中にその都度読み込まれます。

法的情報

プライバシーポリシー

最終更新: 2026年10月

Mapcoder は一切の情報を収集しません。

解析ツールもトラッキングもアカウントもありません。Apple マップから場所を共有すると、座標は共有データそのものに含まれて渡され、マップコードは通信を一切行わずにこの端末上で計算されます。

例外はマップタブだけです。背景地図をオンラインの地図サービスから読み込むため、表示している地図の範囲はそのサービスに伝わります。位置情報や履歴が伝わることはありません。このタブを開かなければ、本アプリは通信を一切行いません。

履歴はこの端末内にのみ保存され、アプリと 2 つの機能拡張で共有される領域に置かれます。外部に送信されることはありません。履歴タブで消去すれば削除され、アプリを削除すればすべて消えます。

位置情報の利用

Mapcoder が位置情報へのアクセス（アプリの使用中のみ）を求めるのは、任意の「現在地」ボタンのためだけです。このボタンを押すと、現在地のマップコードを iPhone 上で計算します。位置情報が外部に送信されることはありません。
